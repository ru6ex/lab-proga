# passenger_transport - лабораторная работа 1

ООП в Python. Обработка исключительных ситуаций. Форматы XML и JSON.

## Предметная область
Пассажирский транспорт (Тема №7)

## Структура проекта
* `models/` — классы предметной области (Автобус, Трамвай, Троллейбус, Метро, Водитель, Маршрут, Фабрика)
* `exceptions.py` — собственные исключения
* `depot.py` — контейнер депо (CRUD-операции)
* `repository.py` — сохранение/загрузка JSON и XML
* `main.py` — точка входа

## Запуск
```bash
python main.py
